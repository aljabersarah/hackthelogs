Virtualization & Cloud Logs

In virtualised and cloud environments the control plane is the new perimeter. An attacker with API credentials does not need to touch a single operating system to copy a disk, snapshot a database, or grant themselves permanent access. Explore how each platform records that activity, and what an attack against the management layer looks like in the logs.

VMware vSphere

ESXi host logs, vCenter events, and vpxd audit trails. Covers hostd and vmkernel output, virtual machine lifecycle events, datastore access, and the shell and lockdown mode activity that reveals hypervisor compromise.

Hyper-V

Hyper-V Worker, VMMS, and Compute event channels plus System Center VMM. Records virtual machine creation and migration, checkpoint activity, virtual switch changes, and shielded VM attestation results.

Amazon Web Services

CloudTrail management and data events, VPC Flow Logs, GuardDuty findings, and S3 access logs. The definitive record of every API call made in the account, and the first place credential abuse becomes visible.

Microsoft Azure

Azure Activity Log, Entra ID sign-in and audit logs, and diagnostic settings. Tracks resource changes, conditional access decisions, consent grants, and the identity attacks that dominate cloud intrusion today.

Google Cloud

Cloud Audit Logs across Admin Activity, Data Access, and Policy Denied streams. Covers IAM policy changes, service account key creation, and the impersonation chains that make GCP privilege escalation possible.

Kubernetes & Containers

API server audit logs, container runtime output, and admission controller decisions. Records exec into pods, privileged container creation, service account token use, and the RBAC changes behind cluster takeover.
