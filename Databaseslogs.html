Database Logs

Databases hold the data attackers are ultimately after, yet database auditing is the most commonly disabled logging in the estate. Explore how each engine records authentication, privilege changes, schema modifications, and data access, and what those records look like when someone is actually stealing your data.

Microsoft SQL Server

SQL Server Audit, Extended Events, the Default Trace, and the SQL Server Error Log. Tracks logon success and failure, privilege escalation, schema changes, and dangerous configuration options such as xp_cmdshell.

Oracle Database

Unified Auditing, Fine-Grained Auditing, the alert log, and the listener log. Provides deep coverage of SYSDBA activity, privilege grants, and sensitive object access across the ADR diagnostic framework.

MySQL / MariaDB

Error log, general query log, slow query log, binary log, and the audit plugin. Essential for spotting brute force logins, INTO OUTFILE web shell drops, and mass data extraction.

PostgreSQL

The server log with CSV and JSON destinations plus the pgAudit extension. Records connections, authentication failures, DDL and role changes, and superuser abuse such as COPY FROM PROGRAM.

MongoDB

Structured JSON mongod logs, the Enterprise audit log, and the database profiler. Critical for detecting exposed unauthenticated instances, ransom-style database drops, and role escalation.
