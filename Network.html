Network Logs

Network logs record every conversation an attacker has to hold in order to reach your data. Command and control beacons, tunnelled exfiltration, lateral movement, and credential relay all cross the wire and leave evidence behind. Explore how each network source records that traffic, and what an intrusion looks like inside it.

IDS / IPS

Snort and Suricata alert logs, EVE JSON output, and signature metadata. Records exploit attempts, malware traffic, policy violations, and protocol anomalies with the rule that fired and the packet that triggered it.

Proxy

Squid, Zscaler, and Blue Coat access logs. The richest source of outbound web visibility: full URLs, categories, user attribution, bytes transferred, and the block decisions that reveal command and control attempts.

VPN

Cisco AnyConnect, FortiGate SSL VPN, and OpenVPN session logs. Tracks remote authentication, assigned tunnel addresses, session duration, and the impossible travel and MFA fatigue patterns that reveal account compromise.

DNS

Windows DNS Server, BIND query logs, and Sysmon event 22. Arguably the highest value network log in a SOC: DNS tunnelling, domain generation algorithms, and newly registered domain lookups all surface here first.

DHCP

Windows DHCP Server audit logs and ISC dhcpd leases. The attribution layer of network forensics: without it, an IP address in every other log cannot be tied back to a physical device or user.

Router & Switch

Cisco IOS, Juniper Junos, and Arista syslog. Records configuration changes, interface state, authentication to the management plane, ACL denials, and the port security events that expose rogue devices.
